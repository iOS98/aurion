# أوريوني — سجل سيارتي

تطبيق ويب (PWA) للآيفون يتولى أمور سيارتي **تويوتا أوريون ٢٠١٥**:
المصاريف حسب القسم، تعبئات الوقود واستهلاك السيارة، ضمانات القطع وأرشفة فواتيرها بعد انتهائها،
مقارنة سعر أي صنف بمشترياتك السابقة، التأمين والاستمارة والفحص الدوري مع تنبيه قبل الانتهاء، وتقارير شاملة.

## التشغيل
- الخادم: Node.js + Express، والبيانات والفواتير في PostgreSQL عبر `DATABASE_URL`.
- بدون `DATABASE_URL` يحفظ في ملفات داخل `DATA_DIR` (للتجربة محليًا).
- متغيرات البيئة: `APP_PIN` (رمز الدخول)، `APP_SECRET` (سر توقيع الجلسة)، `DATABASE_URL`،
  و`CAR_DEFAULTS` (JSON ببيانات السيارة الشخصية مثل رقم الهيكل واللوحة، حتى لا تكون في الكود).

```bash
npm install
APP_PIN=1234 npm start
```

## التثبيت على الآيفون
افتح الرابط في سفاري ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
